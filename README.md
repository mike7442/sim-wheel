# sim-wheel — FFB-руль из мотор-колеса гироскутера

Пошаговое руководство «с нуля»: как из мотор-колеса гироскутера, платы на
MM32SPIN05PF и ESP32-S3 получить работающий force-feedback руль для симрейсинга.

Это **не** описание проекта «вообще», а **инструкция по повторению**: чистый
ноутбук, собранное железо, никакого ИИ и никакого чата. Всё, что нужно, —
команды, ожидаемый вывод и список грабель, на которые уже наступали.

Проверено на реальном железе 2026-11-21…22, вплоть до FFB в Dirt Rally 2.0.

## Что получится

```
        ┌──────────────┐   USB CDC    ┌──────────────┐   UART 115200   ┌──────────────┐
        │     PC       │◄────────────►│   ESP32-S3   │◄───────────────►│  MM32SPIN05  │
        │  игра + vJoy │              │    мост      │   CANSimple     │  FOC + torque│
        └──────┬───────┘              └──────────────┘                 └──────┬───────┘
               │ DirectInput FFB                                             │ 3 фазы
               ▼                                                             ▼
        ┌──────────────┐                                            ┌──────────────┐
        │ vJoy device  │  позиция колеса → ось X                    │  мотор-колесо│
        │  (виртуальный│  FFB игры → magnitude → момент             │  (direct     │
        │   джойстик)  │                                            │   drive)     │
        └──────────────┘                                            └──────────────┘
```

Две встречные петли:

1. **Позиция:** энкодер мотора → `vjoy_ffb.py` → ось X виртуального джойстика → игра.
2. **Момент:** игра шлёт DirectInput-эффект → vJoy → callback pyvjoy → `vjoy_ffb.py`
   → команда момента → MM32 → мотор.

Телеметрия игры не нужна: DR2 отдаёт FFB обычным DirectInput-эффектом.

## Железо (минимум)

- мотор-колесо гироскутера с датчиками Холла;
- плата гироскутера Gen2.x на **MM32SPIN05PF** (с шунтами фаз — иначе FOC/torque невозможны);
- **ESP32-S3** (нужен native USB, не CH340);
- ST-LINK V2 для прошивки;
- БП **42 В** с ограничением тока (родное напряжение 10S), предохранитель 5 А,
  аварийная кнопка.

## Лицензия и статус

Личный проект, выложен как есть, без гарантий. Прошивка платы — сторонняя
(ALIFE, отдельный репозиторий, клонируется скриптом). Скрипты и текст — можно
брать и переделывать.
